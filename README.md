# 📈 Sales Data Dashboard

The Sales Data Dashboard is an interactive Power BI report designed to provide actionable insights into overall sales performance, customer behavior, and product trends. It consolidates key metrics from sales data, offering business users a visual summary to support data-driven decision-making.

# 🎯 Key Insights

The dashboard highlights:

Total Sales: 💰 10.03M

Total Orders: 📦 2,823

Unique Customers: 👥 92

Sales by Status: Tracks shipped, cancelled, and pending orders.

Sales by Product Line: Identifies best-performing categories such as Classic Cars and Vintage Cars.

Sales by Deal Size: Compares contributions from Small, Medium, and Large deals.

Sales by Year: Displays annual performance trends.

Geographic Sales Distribution: Visualizes global sales on an interactive map.

# 🧠 Features

Dynamic Visuals:

Bar charts, line charts, and maps for intuitive understanding.

KPIs for key metrics (Sales, Orders, Customers).

Category Breakdown: Product line and deal size comparisons.

Geographic Insights: Power BI Map visualization for regional sales distribution.

Customer Summary Table: Displays top customers with total sales and quantity ordered.

Interactive Filters & Drill-through: Allow users to explore data from different dimensions.

# 🏗️ Data Model

Dataset: Sales_Data
Key Fields:

CUSTOMER NAME

ORDER NUMBER

STATUS

PRODUCTLINE

DEAL SIZE

COUNTRY

YEAR_ID

QUANTITY ORDERED

SALES
